# Glossary: Chinese (Simplified), zh-Hans

| Concept | Term | Notes |
|---|---|---|
| Addressing the player | 您, mostly left out | Polite neutral, as PlayStation's Chinese system software does. Use 您 only where a pronoun is needed; instructions use 请…. |
| Settings | 设定 | Sony's term on PS Vita/PS4/PS5 (not 设置). Quoted names of menus and values use “…”. |
| Stream (noun/verb) | 串流 | 正在串流, 开始串流, 测试串流 |
| Host (the PC running Sunshine) | 主机 | Host software: 主机程序. Host management: 主机管理 |
| PC / computer | 电脑 | |
| Server | 服务器 | Only where the English says server |
| Pair / unpair / paired | 配对 / 取消配对 / 已配对 | |
| Connect / connection | 连接 | Good connection 连接良好, weak connection 连接较弱 |
| Bitrate | 码率 | Custom bitrate 自定义码率 |
| Frame rate / FPS | 帧率 | "fps" stays as a unit after numbers; overlay value FPS |
| Resolution | 分辨率 | |
| Latency / delay / input lag | 延迟 / 操作延迟 | |
| Stutter | 卡顿 | |
| Lost frames / packet loss | 丢帧 / 丢包 | |
| Wi-Fi signal | Wi-Fi信号 | Wi-Fi and Bluetooth stay in English (as Sony does) |
| V-Sync | 垂直同步 | "（V-Sync）" added once in its help |
| Frame pacer | 帧节奏控制 | |
| Clock boost | 提升频率 / 频率提升 | |
| Auto-detect | 自动检测 | |
| What matters most (priority) | 优先项 (labels), 您最看重的方面 (prose) | Balanced 平衡, Lowest delay 最低延迟, Battery life 电池续航 |
| Recommended settings | 推荐设定 | |
| Benchmark | 基准测试 | |
| Wake on LAN | 网络唤醒 | "WoL only" → 仅唤醒 |
| Front touch screen | 前触摸屏 | |
| Rear touch pad | 背面触摸板 | |
| Touchpad (DS4) / trackpad | 触摸板 / 触控板 | |
| Controller | 控制器 | Sony's term; "Gamepad buttons" → 控制器按钮 |
| Buttons | 按钮 (controller), 按键 (keyboard/mouse) | PS button = PS按钮 |
| Stick | 摇杆 | Double tap to sprint → 双推冲刺 |

| Home screen | 主画面 | |
| Sleep / standby | 待机 | |
| Screen keyboard | 屏幕键盘 | |
| On / off values | 开 / 关 | COMMON_YES/NO and toggles |
| Box art / text list | 封面 / 文字 | |
| Units | {0} 秒, {0} 像素, {0} 字节; Mbps, kbps, ms kept | |
| Punctuation | Full-width ，。：（）“” | No spaces between Chinese and Latin text; ellipsis written ... as in English |
