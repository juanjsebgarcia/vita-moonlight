# Glossary: Portuguese (Brazil), pt-BR

Brazilian Portuguese, also used for Portugal until pt-PT exists. Where it costs nothing, wording is chosen to read well in Portugal too (e.g. "emparelhar", enclitic pronouns such as "desligue-o").

| Concept | Term | Notes |
|---|---|---|
| Addressing the player | **você**, imperative in the 3rd person ("Pressione", "Escolha", "Desative") | As PlayStation's Brazilian system software does. Possessives "o seu PC". Avoid gendered adjectives about the player ("quando quiser começar", not "quando estiver pronto"). |
| Settings | Configurações | Vita/PS BR term (Portugal: Definições). |
| Stream (noun) / streaming | transmissão / transmitir | "Transmitindo {0}". Tab: "Transmitir" (10-char limit). "cliente de streaming" only in About. |
| Host | host | Sunshine is "o host". Used where the English says host; otherwise "PC" or "computador". |
| PC / computer | PC / computador | As in the English. |
| Pair / unpair | emparelhar / desfazer o emparelhamento | Paired = emparelhado; Unpaired = não emparelhado. |
| Bitrate | taxa de bits | Custom value: "Personalizada" (feminine, agrees with taxa). |
| Frame rate / FPS | taxa de quadros / FPS | Frame = quadro. "fps" stays in units and overlay values. |
