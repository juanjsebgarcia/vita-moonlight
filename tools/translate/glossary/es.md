# Spanish (es) glossary

One Spanish for Spain and Latin America: neutral wording, "PC" for the computer (never "ordenador" or "computadora").

| Concept | Spanish | Notes |
|---|---|---|
| Addressing the player | tú | As PlayStation does: "Pulsa", "Elige", "tu PC". |
| Settings | Ajustes | Sony's term. A single setting: "ajuste". |
| Stream (noun) / to stream | transmisión / transmitir | "Transmitiendo {0}", "durante la transmisión". |
| Stream tab | Streaming | "Transmisión" is too long for a tab (10 chars max). |
| Host / PC | PC (masc., invariable plural: "PC vinculados") | "host" kept where the English says host as a label ("Gestión del host", "Host: {0}", "Host eliminado"). |
| Server | servidor | Only where the English says server. |
| Pair / unpair / paired | vincular / desvincular / vinculado | |
| Bitrate | tasa de bits | Value "Personalizada" (feminine, agrees with tasa). |
| Frame / frame rate | fotograma / FPS, fotogramas por segundo | FPS stays FPS; stats value "fps" stays. |
| Resolution | resolución | |
| Connection | conexión | Good/Weak: Buena conexión / Conexión débil; values Buena / Débil. |
| Wi-Fi signal | señal Wi-Fi | "el Wi-Fi" (masc.). Percent written "60 %" with a space. |
| Lag / delay / input lag | retraso / retraso de entrada | "latencia" only where the English says latency. |
| Stutter | dar tirones / tirón | |
