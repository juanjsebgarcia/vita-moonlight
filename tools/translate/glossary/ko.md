# Korean (ko) glossary

## Address and style

- Polite, neutral form as in PlayStation's Korean system software: statements end in -습니다/-ㅂ니다, instructions in -하세요, confirmations in -하시겠습니까?
- "You/your" is mostly left out, as is natural in Korean.
- Settings rows, headings and statuses are noun phrases (…사용, …바꾸기, 페어링됨).
- After a button marker, write 버튼 so the particle is always right: `{triangle} 버튼을 누르세요`, `{left}/{right} 버튼으로`. Where a PC or app name ({0}) needs a particle, prefer 의/에/에서 (they don't change with the name); use 을(를) only when unavoidable.
